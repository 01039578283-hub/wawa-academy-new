01

출처와 현재 범위를 먼저 확인하세요

자료를 받은 곳과 날짜, 어떤 단원·과제에 쓰는지 적습니다. 기출이나 예상이라는 이름만으로 현재 학교 범위에 맞거나 실제 출제가 보장된다고 보지 마세요. 시험 안내와 다른 조건은 별도로 표시합니다.

학교와 학원이 제공한 자료라도 현재 과제에 필요한지 확인합니다. 무단으로 공개된 자료나 출처가 불분명한 문항은 원래 안내와 사용 조건을 살펴보세요.

02

자료별로 사용할 목적을 정하세요

풀이 영상은 막힌 단계의 설명을 확인할 때, 요약본은 개념을 다시 찾을 때, 문제 자료는 혼자 적용하고 확인할 때 사용할 수 있습니다. 한 자료가 여러 역할을 할 수도 있으므로 실제 행동으로 적어 보세요.

영상을 끝까지 봤다는 기록과 혼자 풀이한 결과는 다릅니다. 막힌 설명을 본 뒤 화면을 닫고 해당 개념을 짧게 설명하거나 유사 과제를 시도합니다.

03

기존 교재와 겹치는 과제는 선택하세요

같은 개념과 난도의 과제를 여러 자료에서 반복한다면 현재 목표에 필요한 묶음을 고를 수 있습니다. 다른 자료를 쓰기 전에 지금 교재에서 무엇이 부족한지 적어 보세요.

모든 자료를 끝내는 대신 오류가 반복되는 대표 과제와 조건이 다른 확인 과제를 선택합니다. 분량을 줄여도 설명·적용·재확인이 빠지지 않았는지 살펴보세요.
