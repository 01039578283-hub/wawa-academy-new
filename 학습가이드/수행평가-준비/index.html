먼저 확인할 답

먼저 안내문에서 평가하는 내용, 제출 형식, 마감, 개인·모둠의 역할을 찾아 목록으로 만드세요. 꾸미기나 분량 늘리기보다 ‘어떤 근거를 어떤 방식으로 보여 달라는지’를 확인하고 초안을 준비하는 편이 과제를 관리하기 쉽습니다.

실천 순서

  1. 평가 요소를 질문으로 바꾸기

    ‘자료 활용’이라는 항목을 ‘어떤 자료를 왜 골랐는가를 설명했나?’로 바꿉니다. 발표 길이·분량·파일 형식은 안내문 그대로 적고, 허용 도구나 공동 작업 조건이 불분명하면 담당 교사에게 확인합니다.

  2. 작업을 자료·초안·검토로 나누기

    자료를 찾는 날과 내용을 구성하는 날, 제출 조건을 확인하는 날을 구분합니다. 모둠이면 맡은 범위와 자료 전달 시점을 적으세요. 내용 검토 없이 디자인만 먼저 끝내지 않습니다.

  3. 원문과 자신의 설명 구분하기

    사용한 자료의 작성자·제목·날짜·주소를 남기고 인용 부분을 표시합니다. 출처가 불분명한 이미지나 생성 도구의 답을 그대로 근거로 쓰지 마세요. 학교가 안내한 도구 사용 범위를 따릅니다.

  4. 평가표와 초안을 한 줄씩 대조하기

    제목, 주장, 근거, 단위, 출처, 제출 형식을 체크합니다. 빠진 항목을 고친 뒤 실제 파일이 열리는지도 확인하세요. 발표라면 문서를 읽는 연습과 제한 안에서 설명하는 연습을 구분합니다.

놓치기 쉬운 부분

  • 분량이 많아도 질문에 답하지 않으면 필요한 내용을 놓칠 수 있습니다. 평가 요소별로 보여 줄 근거를 먼저 정합니다.
  • 모둠의 최종 파일만 기다리면 자신의 역할이 빠질 수 있습니다. 담당 부분과 합치는 시간을 기록하세요.
