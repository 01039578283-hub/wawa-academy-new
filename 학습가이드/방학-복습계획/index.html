먼저 확인할 답

지난 학기 교재를 전부 다시 시작하기 전에 지금도 혼자 하기 어려운 개념과 과제를 골라 보세요. 방학 목표를 ‘문제집 한 권’만으로 정하지 말고 설명·풀이·쓰기 중 어떤 수행을 다시 할 수 있게 만들지 적으면 중간 점검이 쉬워집니다.

실천 순서

  1. 최근 기록에서 반복 빈틈 고르기

    시험지, 숙제, 오답 기록에서 반복해서 질문한 내용을 찾습니다. 한 번 틀린 낯선 문제와 같은 개념에서 반복되는 어려움을 구분하고, 현재 대표 과제를 다시 시도해 확인합니다.

  2. 한 목표에 필요한 자료 정하기

    교과서 설명, 기존 풀이, 짧은 연습 문제처럼 역할별 자료를 고릅니다. 이미 가진 교재의 필요한 부분을 활용할 수 있는지 먼저 보고, 새 교재는 그 자료로 해결하기 어려운 역할이 있을 때 검토하세요.

  3. 복습과 새로운 학습의 비중 조정하기

    현재 개념 설명과 기본 적용이 불안정하면 복습을 먼저 배치합니다. 새 내용은 시작 범위와 다시 확인할 기준을 함께 정하세요. 여행·휴식·학교 과제 일정도 실제 가능한 시간에 포함해 계획합니다.

  4. 방학 중간과 끝에 같은 수행 확인하기

    처음 골랐던 과제를 답을 가리고 다시 시도하거나 비슷한 새 예시를 사용합니다. 필요한 도움과 걸린 시간을 함께 남기고, 해결되지 않은 질문은 다음 학기 첫 점검으로 연결합니다.
