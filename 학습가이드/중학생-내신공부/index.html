먼저 확인할 답

학교가 안내한 범위에 교과서와 배부 자료를 연결한 뒤, 과목마다 필요한 수행을 정하세요. 수학은 개념과 풀이, 영어는 문장과 표현, 국어·사회·과학은 자료 근거와 설명을 확인합니다. 모든 과목을 같은 암기 방식으로 처리할 필요는 없습니다.

실천 순서

  1. 범위와 자료 위치 연결하기

    단원명 옆에 교과서 쪽과 해당 프린트의 위치를 적습니다. 보충 교재가 시험 범위인지 모호하면 확인 목록에 둡니다. 시험 전 과제나 수행평가 일정도 따로 기록하세요.

  2. 자료별로 혼자 해 볼 과제 정하기

    수학은 정의를 설명하고 기본 문제를, 영어는 문장 조건에 맞는 쓰기를 시도합니다. 사회·과학은 표나 현상의 이유를 짧게 설명해 보세요. 읽은 횟수와 실제 수행을 같은 것으로 표시하지 않습니다.

  3. 학교 수업의 수정 표시 확인하기

    수업에서 고친 식·표현·답안 근거를 찾아 왜 수정했는지 설명합니다. 학교마다 평가 방식이 다르므로 특정 출제 비중을 가정하지 말고 실제 안내와 받은 피드백을 기준으로 삼습니다.

  4. 남은 질문을 자료와 함께 가져가기

    ‘전체가 어렵다’보다 ‘교과서 이 문장과 그래프의 관계를 설명하기 어렵다’처럼 질문합니다. 설명을 받은 뒤 다른 예시에서 다시 시도하고, 도움 없이 가능한 범위를 갱신합니다.
