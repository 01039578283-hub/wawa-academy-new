먼저 확인할 답

점수 외에 학생이 실제로 한 과제와 도움 받은 부분을 준비하세요. 자료가 많을 필요는 없으며 현재 어려움을 보여 주는 풀이와 질문이 있으면 됩니다. 상담 뒤에는 바꿀 행동, 담당할 역할, 다음 확인 자료를 정해 생활에서 실행할 수 있는지 봅니다.

실천 순서

  1. 상담 목적과 학생 의견 정리하기

    궁금한 과목과 상황을 좁혀 적고 학생에게 어떤 부분이 어려운지 물어봅니다. 원하는 도움과 걱정하는 부담을 구분하세요. 학생의 답을 부모의 추측으로 대신하지 않습니다.

  2. 실제 자료와 도움 수준 준비하기

    시험지나 과제, 풀이, 최근 기록 중 현재 질문과 관련된 자료를 고릅니다. 혼자 수행한 부분과 설명을 받은 부분을 표시하세요. 개인정보가 드러나는 불필요한 자료는 가져오지 않아도 됩니다.

  3. 구체적인 도움과 확인 방식 묻기

    어느 개념이나 과제에서 막히는지, 어떤 설명·연습이 필요한지 질문합니다. 수업 여부를 검토한다면 실제 대상과 운영 조건도 따로 확인하세요. 일정이나 지원 범위를 임의로 가정하지 않습니다.

  4. 다음 행동과 확인 자료 정리하기

    학생·가정·지도자가 할 일을 실행 가능한 범위로 정합니다. 다음에는 새 문제 풀이, 질문 기록 등 무엇으로 확인할지 합의하세요. 상담 약속이 실제 생활에 맞는지 학생과 다시 이야기합니다.
